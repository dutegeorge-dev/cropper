# Быстрая пакетная обрезка фотографий

Десктопное приложение показывает фотографию, затемняет всё вне рамки и позволяет
перемещать либо растягивать рамку мышью. Рамка всегда сохраняет выбранное
соотношение сторон. После сохранения автоматически открывается следующий файл.

## Запуск из исходников

Нужен Python 3.10 или новее. В **PowerShell** из папки проекта выполните команды
ниже. Активировать окружение не требуется: явный путь к `python.exe` работает
даже там, где политика PowerShell запрещает запуск `Activate.ps1`.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install pyside6 pillow pillow-heif av pyinstaller
.\.venv\Scripts\python.exe crop_tool.py
```

Если команда `py` отсутствует, установите Python с
[python.org](https://www.python.org/downloads/windows/), отметив в установщике
**Add python.exe to PATH**, а затем откройте новое окно PowerShell. Вызов
`python -m pip` через полный путь гарантирует установку пакетов именно в `.venv`.

Нажмите **«Открыть папку…»**. По умолчанию результат попадёт в подпапку
`cropped`; при необходимости выберите другую папку назначения.

## Управление

* мышь внутри рамки — перемещение; белые угловые маркеры — изменение размера;
* `Enter` или `Пробел` — обрезать, сохранить и открыть следующее фото;
* `←` / `→` — предыдущее фото / пропустить;
* кнопки **«90° влево/вправо»** или `Ctrl+←` / `Ctrl+→` — повернуть текущее
  фото на 90 градусов;
* `1`, `2`, `3`, `4` — рамки 16:10, 16:9, 4:3 и 1:1 соответственно.

Поворот применяется к сохраняемому результату. После поворота рамка заново
становится максимальной, вписанной по центру фотографии, чтобы её можно было
сразу разместить в новой ориентации.

### Карусель и коллажи

Под большой областью просмотра находится карусель из девяти ближайших фотографий.
Текущая фотография отмечена синей рамкой; клик по любой миниатюре сразу открывает
её. Фотографии, добавленные в будущий коллаж, подсвечиваются зелёным.

Чтобы создать коллаж:

1. Откройте нужное фото в карусели и нажмите **«Добавить текущее фото»**.
2. Повторите для остальных фотографий (не менее двух). Повороты фотографий
   запоминаются и используются в коллаже.
3. Выберите формат рамки — 16:10, 16:9, 4:3 или 1:1 — и формат файла JPG/PNG.
4. Нажмите **«Создать коллаж»**. Приложение автоматически создаст сетку с белыми
   полями, заполнит ячейки фотографиями с обрезкой по центру и сохранит файл с
   именем вроде `collage_16x9.jpg` в папку назначения.

Если включено ограничение длинной стороны, оно задаёт размер холста коллажа.
Иначе размер холста выбирается по самому крупному исходнику. Существующие файлы
не перезаписываются: к имени автоматически добавляется индекс.

### Извлечение кадров из видео

В папке с исходниками приложение также находит файлы `.mov` и `.mp4`. При
открытии видео появляется временная шкала и кнопки **«← Кадр»** / **«Кадр →»**:

1. Перетащите ползунок примерно к нужному месту ролика.
2. Кнопками покадрового перехода выберите точный кадр.
3. При необходимости поверните изображение и настройте рамку обрезки.
4. Нажмите **«Сохранить кадр»**, `Enter` или `Пробел`.

Кадр сохраняется как JPG или PNG с текущими настройками качества и рамки, а
видео остаётся открытым для извлечения следующего кадра. В имя добавляется время
кадра в миллисекундах, например `clip_000012340ms_16x9.jpg`. Кадры видео также
можно добавлять в коллаж; для каждого видео используется последняя выбранная
позиция.

Имена создаются автоматически (`IMG_1234_16x9.jpg`). Если имя занято,
приложение добавит `_2`, `_3` и т. д. Изображение не масштабируется, пока не
включена опция ограничения длинной стороны. Для JPG доступно качество 1–100
(по умолчанию 95); PNG использует сжатие без потерь.

## Сборка одного `.exe` для Windows

Собирать Windows-приложение нужно **на Windows** (PyInstaller не является
кросс-компилятором). После установки зависимостей достаточно команды; окружение
активировать не нужно:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name PhotoCropper --collect-all PySide6 --collect-all PIL --collect-all pillow_heif --collect-all av crop_tool.py
```

Готовый файл находится в `dist\PhotoCropper.exe`. Флаг `--windowed` убирает
консоль, `--onefile` упаковывает приложение в один файл, а `--collect-all`
явно включает плагины Qt (в частности, платформенный плагин Windows), модули
Pillow, нативный HEIF/HEIC-декодер из `pillow-heif` и видеодекодеры PyAV. Первый
запуск onefile-сборки может быть чуть медленнее: файлы временно распаковываются
системой.

Если установлен старый PyInstaller или возникает ошибка о Qt platform plugin,
обновите инструменты и пересоберите проект с очисткой:

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pyside6 pillow pillow-heif av pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name PhotoCropper --collect-all PySide6 --collect-all PIL --collect-all pillow_heif --collect-all av crop_tool.py
```

Не используйте одновременно PyQt и PySide в том же виртуальном окружении:
PyInstaller может обнаружить обе Qt-привязки и остановить сборку. Самый простой
способ избежать конфликта — чистое окружение `.venv`, созданное командами выше.

Если активация всё же нужна, её можно разрешить только для текущего окна
PowerShell, не меняя системные настройки:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## Ошибки и форматы

Поддерживаются изображения `.jpg`, `.jpeg`, `.png`, `.webp`, `.heic`, `.heif` и
видео `.mov`, `.mp4`. Файлы HEIC
открываются через `pillow-heif`; результат, как и для остальных исходников,
сохраняется в выбранный JPG или PNG. Битые файлы показываются в предупреждении и
пропускаются. При невозможности создать папку или записать файл приложение
показывает ошибку и остаётся на текущей фотографии, поэтому рамку не нужно
выставлять заново. Видео декодируется библиотекой PyAV, которая устанавливается
вместе с собственными FFmpeg-библиотеками; отдельная установка FFmpeg не нужна.
